# CristianCC3.github.io
Proyecto Final Grado Superior. A continuación presento los Planos y archivos 3D de mi proyecto de final de grado realizado en el 2023. Este proyecto consistió en diseñar y programar la producción de un ensamblaje a libre elección. Mi elección fue un Swashplate, un conjunto usado en los helicópteros el cual se encarga de la rotación de las hélices.
